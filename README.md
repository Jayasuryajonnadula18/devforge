# DevForge — The Architecture of Real-World Systems

> Master the fundamentals. Engineer real systems. Understand how software truly works from the ground up.

DevForge is a high-craft engineering platform combining interactive project tracks, a browser-based split-pane studio IDE, and a cinematic 3D scroll-driven brand experience.

---

## ✨ Features

- **Cinematic 3D Scroll Narrative (Three.js + GSAP ScrollTrigger)**:
  - **Scene 01 — The Ground Up**: Monumental typography with WebThreads volumetric aura and minimalist floating Adelos navigation.
  - **Scene 02 — The Forge & Impact**: Solid, authentic London-pattern blacksmith anvil with milled steel faceplate and sledgehammer poised at $45^\circ$, accelerating into a strike with physical sparks and shockwave.
  - **Scene 03 — The Knowledge Cube**: Anvil shatters into 26 coordinated forged steel blocks that scatter into suspended 3D space, then converge via natural magnetic kinematics (orbital parabolic flight paths and micro-settle damping) into an isometric $3 \times 3 \times 3$ modular cube with chiaroscuro studio rim lighting.
- **Interactive Engineering Studio**:
  - Split-pane workspace (Focused Milestone Spec + Multi-file Code Editor + Terminal Console).
  - Built-in test runner with real-time assertion verification and stage advancement.
  - Command palette (`⌘K` / `Ctrl+K`) for fast project and file switching.
  - Interactive project catalog spanning Go, Python, and Rust system tracks.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org) (Turbopack, App Router)
- **UI Library**: React 19, Tailwind CSS v4, Motion (Framer Motion)
- **3D & Creative Physics**: [Three.js](https://threejs.org), GSAP ([ScrollTrigger](https://greensock.com/scrolltrigger/))
- **Icons & Primitives**: Lucide React, Radix UI Tooltip, Sonner
- **Typography**: Rector Serif, Acma, Inter, JetBrains Mono

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm, pnpm, or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Jayasuryajonnadula18/devforge.git

# Enter project directory
cd devforge

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build

```bash
npm run build
npm run start
```
